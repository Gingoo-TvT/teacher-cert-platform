📝 总体评估

📋 总体评估

项目概况：teacher-cert-platform 是一个教师资格认证业务平台，后端为 Spring Boot 3.4 多模块 Maven 工程，包含 common/security/system/business/exchange/statistics/file/boot 等模块；前端为 Vue 3 + TypeScript + Vite + Naive UI + ECharts；持久化依赖 MySQL、Flyway、Redis、MinIO，并有 Docker 与 GitHub Actions 交付配置。

项目地图：请求入口主要在 platform-boot controller，认证授权在 platform-security 的 JWT filter、AuthService、PermissionService 与数据范围切面，核心业务在 platform-business，交换导入导出在 platform-exchange，文件对象在 platform-file，统计与系统审计/备份在 platform-statistics 和 platform-system。主要数据流为 HTTP API → RBAC/数据范围 → service 事务 → mapper/DB/MinIO → VO/文件导出。

主要风险：最需要先处理的是公开固定初始口令、可预测学生初始口令、浏览器 token 存储，以及当前后端 mvn verify 不通过。它们分别影响账号接管窗口、隐私边界和发布门禁可信度。

亮点：生产配置显式关闭接口文档，JWT 密钥缺失或过短会启动失败，JWT filter 会校验 token 类型、撤销状态和用户启用状态，敏感证件号接口有权限与审计保护，数据库层增加了活跃证书和学生证件号唯一约束，后端集成测试覆盖了不少真实 HTTP/RBAC 流程。

优先修复：先清除默认/可预测口令与后端测试失败，再补前端测试和 release hardening；随后拆分两个巨型服务类，并为隐私字段引入加密/摘要键策略。

总评：Overall 5.9 / B。项目不是失控状态，已有较多工程化控制，但距离稳定公开发布还差几项会直接影响账号安全、验证可信度和上线可控性的修复。

1. 生产 bootstrap admin 与 STAFF 重置使用公开固定初始口令

High Confirmed Confidence High
📁 Security / Configuration / Release📍 V8__rbac_seed.sql, SecurityAdminServiceImpl.java🎯 初始账号与重置密码
问题：Flyway V8 会创建启用状态的 admin，并赋予 SYS_ADMIN；生产清理迁移删除 test_* 但保留 admin。管理员创建 STAFF 和重置密码时也使用同一个配置项的默认口令。must_change_pwd 会限制大多数 API，但 change-pwd 端点必须允许访问，因此第一个拿到公开默认口令的人可以抢先改密接管账号。

3. 浏览器 token 存入 localStorage 且生产 nginx 未配置 CSP

MediumConfirmedConfidence High
📁 Security / Privacy / Frontend-State📍 frontend/src/stores/user.ts, frontend/nginx.conf🎯 会话令牌存储
问题：accessToken 和 refreshToken 持久化在 localStorage，请求拦截器读取后放入 Bearer header；生产 nginx 只有 XFO、nosniff、Referrer-Policy，没有 CSP。代码未发现 v-html，但一旦发生 XSS、依赖注入或浏览器扩展污染，刷新令牌可被脚本直接读取。
为什么重要：refresh token 泄露会把一次 XSS 扩大为持续会话接管。
现实场景：某个前端依赖或富文本输入引入脚本执行，攻击脚本读取 localStorage 并将 refreshToken 发往外部，随后在用户离线时继续刷新会话。

最小修复：增加严格 CSP，例如 default-src 'self'; script-src 'self'; object-src 'none'; base-uri 'self'；缩短 access token TTL。 长期修复：refresh token 改为 HttpOnly + Secure + SameSite cookie 或 BFF session；前端只在内存持有短期 access token。
⏱ 估计工作量：1-2 天  ·  回归测试：新增 Playwright 测试验证登录/刷新仍可用，并用测试页面注入脚本确认无法读取 refresh token；检查响应包含 CSP。

5. 身份证号明文持久化并参与数据库唯一键
