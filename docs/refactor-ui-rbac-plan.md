# 收官后重构计划 · UI 重建 + RBAC/流程调整（Phase 15–24）

> 基线：Phase 0–14 + T-115 已收官（`mvn verify` 75/75 绿，本地私有）。本计划为收官后的重构初始化，按既有节奏 **codex 实现一个 Phase → Claude 按 `docs/REVIEW-GATE.md` 复核 → `--ff-only` 合并 main → 放行下一 Phase**。git 全程本地私有、无 remote、不 push；验证一律 build-only 防卡死（`mvn -B -ntp verify` + 前端 `type-check`/`build`，不前台起 java-jar/vite/常驻容器）；codex 不自评 ✅（置「待复核」）。

## 0. 来源与依据
- **权威字段文档**（微信收到，已抽取）：`师范生教育教学能力考核平台字段要求.doc` + `导入导出信息.xlsx`（26 列模板 + 25 条填表说明 + 任教学科表）。要点：全字段文本、导出不得数字转换；一批字段为固定枚举/联动（见附录 A）；免考二级审核；视频两位教师评审、15 分钟 MP4；证书号 18 位规则、有效期 6/30·12/31。
- **两版前端盘点**：前瞻版 `teacher-cert-ui-preview`（Naive UI，设计系统/角色感知工作台/主从布局等更精致，但**纯 mock 无后端**）；生产版 `teacher-cert-platform/frontend`（真实 18 API 模块 + stores + 按权限菜单，但 UI 较朴素）。
- **用户已确认 4 项决策**：
  1. 学院审核模型：**教务员保留初审**（教务员=查看+初审；复审及其他动作归学院负责人）。
  2. 前端方式：**以前瞻版为底重建**（前瞻版 UI 基座 + 生产版真实 API + 按权限菜单）。
  3. 证书签发：**删除 CERT_ISSUER**，cert:issue 并入教务处/全校管理员。
  4. 评审分组：**现在就做**。

## 1. 最终 RBAC 角色权限矩阵（Phase 15 落地）
| 角色 | 定位 | 权限要点 |
|---|---|---|
| SYS_ADMIN 系统管理员 | 超级管理员 | **全部权限**（V20 关联 sys_permission 全表） |
| ACADEMIC_ADMIN 教务处/全校管理员 | 校级 | 全校业务 + 证书 generate/correct/void/reissue + **cert:issue（并入签发）** + 基础数据维护 |
| COLLEGE_AUDITOR → 学院负责人(副院长) | 学院动作role | **复审**(student/training/material/exemption) + **video:assign 指派评审** + arbitrate + 学院数据录入/导入/prevalidate + 其他动作 |
| COLLEGE_CLERK 学院教务员 | **只读 + 初审** | 全部 `*:view` + **初审**(各业务 firstReview) + 只读导出/批量下载 + notice/stats/audit/dict view。移除 edit/import/test:*/assign/secondReview/manage |
| REVIEW_TEACHER 评审教师 | 评审 | video:score + video:play（按指派/分组评分） |
| ~~CERT_ISSUER~~ | **删除** | cert:issue 归 ACADEMIC_ADMIN；test_cert_issuer 改授 ACADEMIC_ADMIN 或停用 |
| STUDENT 学生 | 本人 | confirm/upload/apply/视频上传（含退回后可重传） |

> 数据范围（college/self/assigned/school）语义不变，本次只改「谁拥有动作权」。

## 2. 阶段与任务分解（Phase 15–24，T-116~T-161）

### Phase 15 · RBAC 基座（WP-A，后端为主）
- **T-116** V20 迁移：按 §1 矩阵重配 sys_role_permission（SYS_ADMIN 全权 / ACADEMIC_ADMIN +cert:issue / AUDITOR 接动作权 / CLERK 收敛只读+初审 / 删 CERT_ISSUER 关联），幂等可重跑；不改 V1–V19。
- **T-117** SYS_ADMIN 超级权限鉴权核对（确保取得全部权限后既有 perm 校验放行；复用既有 superuser 旁路或种子给齐，勿引新机制）。
- **T-118** 删除 CERT_ISSUER 角色与关联；处理 test_cert_issuer 账号（改授 ACADEMIC_ADMIN 或停用，DEVLOG 说明）。
- **T-119** 受影响 IT 改到新模型：clerk 的 assign/import/edit/secondReview → auditor/academic；cert:issue → academic；clerk 仍可 firstReview。
- **T-120** 前端权限常量/菜单最小适配（仅保编译与基本可用，不重构 UI）。
- **复核门槛**：`mvn verify` 全绿（新模型下）；权限矩阵逐角色核验；越权/数据范围未回归；V20 幂等、V1–V19 冻结。

### Phase 16 · 测试结果只确认（WP-B，后端+少量前端）
- **T-121** 移除/禁用测试结果手工录入接口（POST/PUT /test 创建编辑），保留导入(/test/import,/test/import-file)+确认(/test/{id}/confirm)。
- **T-122** 权限收口：移除 test:edit（手工录入）授权；test:import/test:confirm 按矩阵归属（academic/auditor）。
- **T-123** 成绩文本化与「结论有效性→证书前置」契约不变性校验（导入→确认→证书前置链路）。
- **T-124** 受影响 IT 调整（Phase8 录入用例改导入+确认路径）。
- **复核门槛**：无手工录入入口；导入+确认链路绿；前导零成绩文本/有效性契约不变；回归绿。

### Phase 17 · 视频退回可重传（WP-C，后端+少量前端）
- **T-125** 视频评审状态机增「退回(RETURNED)」态与退回动作（负责人/评审触发，记审计 old/new/意见）。
- **T-126** 可编辑守卫：退回态允许学生重传（接 Phase 7 `ensureReuploadable`；重传清理旧任务/分片/分数）。
- **T-127** 重传后重新进入评审流（重置评分任务、通知触发）。

- **复核门槛**：退回→重传→复评闭环绿；REVIEWING/NEED_REVIEW/已结算态仍拒绝重传；审计留痕；回归绿。

### Phase 18 · 评审指定与分组（WP-D，后端+少量前端）

- **T-131** 数据范围硬校验：组/指派限本学院；跨院越权拒绝。

- **复核门槛**：建组/按组指派/按人指派均绿；越权拒绝；两位评审+需复评+第三专家结算不破；回归绿。

## 3. 复核节奏（按阶段）
每个 Phase：codex 单分支实现 → PROGRESS 置「待复核」→ 用户「复核」→ Claude 独立 `mvn verify`/读码/（必要时）派代理 → PASS（✅ + `--ff-only` 合并 main + 放行下一 Phase）或 退回（列 Blocker/Major + 修复提示，不合并）。迁移按磁盘 max+1（V20、V21…）。前端重建各 Phase 以「可编译可联通 + 该域功能可用 + 不破坏后端契约」为门槛。

## 附录 A · 字段规范（来自权威文档，落到下拉/联动）
- **性别**：男 / 女。
- **身份证件类型(4)**：居民身份证 / 港澳台居民居住证 / 港澳居民来往内地通行证 / 五年有效期台湾居民来往大陆通行证。
- **身份类型(5)**：教育类研究生 / 公费师范生 / 普通师范生 / 优师计划师范生 / 国优计划师范生。
- **学历层次(4)**：博士研究生 / 硕士研究生 / 本科 / 专科。
- **专业培养目标(5)**：幼儿园教师 / 小学教师 / 初级中学教师 / 高级中学教师 / 中等职业学校教师。
- **教育实习实践组织方式(2)**：学校组织 / 个人联系。
- **教育实习实践地点(5)**：幼儿园 / 中小学 / 企业（职业技术教育专业）/ 海外（汉语国际教育专业）/ 其他。
- **任教学段(5)**：幼儿园 / 小学 / 初级中学 / 高级中学 / 中等职业学校。
- **面试考试组织方式(2)**：结合教育实习实践环节一并考核 / 单独面试。
- **联动**：学段→任教学科（幼儿园仅「幼儿园」；小/初/高/中职文化课按学科表；中职可选中职专业课具体学科）；培养目标→实习地点（中职→其他、高中→中小学）；身份类型→专业代码规则（教育类研究生前四位 0401/0451/0453）。
- **证书号 18 位**：年份4 + 学校5 + 层次1(博1硕2本3专4) + 省2 + 学段1(幼1小2初3高4中职5) + 序号5（同校同年递增）。
- **有效期**：上半年→6/30、下半年→12/31，+3 年。
- **全字段文本，导出不得数字转换**（沿用既有标准导出 @ 文本化契约）。
