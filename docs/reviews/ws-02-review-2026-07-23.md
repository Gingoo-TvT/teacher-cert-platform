## 独立性与范围

复核覆盖生产管理员/职工初始化、学生开户与重置、并发改密和 token 撤销；测试由复核者在真实 MySQL/Redis 环境重跑，不以提交说明为证据。

## 结论依据

- prod 管理员初始化必须提供合法 BCrypt hash，成本至少 10，并拒绝公开默认口令 hash；一次性替换使用 CAS，替换前后撤销会话。
- prod STAFF 初始口令缺失/弱值会 fail-fast；dev 默认值只在显式 dev profile 下生效。
- V27 默认关闭学生自动开户并停用“证件号后六位”策略；学生流程只有受控强口令才创建启用账号。
- 学生密码重置生成随机 20 位口令，基于旧 hash CAS 更新并撤销 token；登录/改密并发路径有 session generation 防护。
- 目标单测组合 **105/105**；含 `CredentialHardeningIT` 的真实依赖专项组合 **50/50**；全量 **265/265**。
