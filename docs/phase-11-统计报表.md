# Phase 11 · 统计查询与报表（M11）

> 优先级 P1 · 依赖：Phase 3~10 · 任务：T-092~T-100 · plan §十一 / §M11
> 目标：8 类统计 + ECharts 图表 + Excel 导出，全部受数据范围约束、与明细对账一致。

## 1. 八类统计（维度 → 输出）
| 统计 | 维度 | 输出 |
|---|---|---|
| 学院提交进度 | 学院/专业/班级/学生状态 | 进度表、柱状图、Excel |
| 材料完成率 | 四类材料/初复审状态/退回原因 | 统计表、异常清单 |
| 免考统计 | 科目/学院/专业/通过-不通过 | 统计表、明细 |
| 视频评审进度 | 已/未上传、待评审、已评审、需复评 | 进度看板、专家任务表 |
| 证书生成统计 | 待生成/已生成/已签发/已作废/已导出 | 证书清单、汇总 |
| 任教学段/学科 | 学段/学科/身份类型/学历层次 | 交叉表 |
| 异常数据 | 字段缺失/证件/专业代码/证书编号/学段学科不匹配 | 异常报告、整改清单 |
| 导入导出日志 | 批次/操作人/时间/成功失败/范围 | 审计报表 |

## 2. 接口与前端
- 每类 `GET /api/stats/{type}?维度参数...` + `POST /api/stats/{type}/export`（权限 `stats:view`，数据范围生效）。
- 前端统计页：ECharts 图表 + 表格 + Excel 导出；钻取到明细。

## 3. 验收清单
- [x] 八类统计均可查、可导出 Excel；图表与表格数据一致。
- [x] 统计数与对应明细对账一致（抽 2 类做对账）。
- [x] 数据范围生效：学院用户只统计本院；教务处统计全校。
- [x] 异常数据统计可定位到具体学生/字段。

## 4. 测试用例
- T-STAT-1：材料完成率 = 已合格人数/应交人数，与明细计数一致。
- T-STAT-2（反例）：学院A用户统计 → 不含学院B数据。
- T-STAT-3：证书生成统计各状态计数 = 证书清单分组计数。

## 5. DoD
八类统计 + 图表 + 导出 + 钻取可用，口径与明细一致，受数据范围约束。

## 6. 风险
- 统计口径（分母如"应交人数"）需与教务处确认；先按当前考核年度在册学生计。
